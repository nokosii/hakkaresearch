# 臺灣客家知識體系觀察站

觀察三所大學客家學院專任師資的客家相關研究成果：

- 國立聯合大學 客家研究學院（客家語言與傳播研究所、文化觀光產業學系、文化創意與數位行銷學系）
- 國立中央大學 客家學院（客家語文暨社會科學學系、法律與政府研究所）
- 國立陽明交通大學 客家文化學院（人文社會學系、傳播與科技學系）

網站是純靜態頁面（`index.html` + `assets/` + `data/`），可直接以 GitHub Pages 發布，也可以在本機直接開啟 `index.html`。

## 頁面

- **總覽**：三校比較、客家研究投入程度圖表、年度產出趨勢、系所一覽
- **師資名錄**：可依學校、系所篩選、排序；點選教師進入個人頁
- **個人頁（佐證資料）**：列出逐筆被計入的客家相關著作與國科會計畫（附國科會原始頁面連結）、客庄地域／間接相關條目、系所個人頁補充條目、客家淵源紀錄
- **方法與限制**：判定規則、關鍵詞、資料限制

## 資料來源

| 項目 | 來源 |
|---|---|
| 專任師資名單 | 各系所官方網站師資頁 |
| 著作、計畫 | 國家科學及技術委員會「研究人才查詢」：著作目錄、計畫總覽 |
| 客家事務專業獎章 | 客家委員會 111、112、114 年獲獎名單公告 |

## 「客家淵源／客籍」的處理原則

族群身分屬於個人資料。本站**不**依姓氏、籍貫或研究主題推論任何人的族群，只在下列情況標示並附出處：

1. **本人公開自述**：寫入 `data/heritage.json`，每筆必須附原文與網址，格式如下：

```json
{
  "ncu-王保鍵": { "self": { "quote": "（原文摘錄）", "url": "https://..." } }
}
```

2. **客家事務專業獎章**：依客家委員會公告名單的姓名比對。

「未見公開紀錄」只表示尚未查得公開資料，不代表當事人不具客家淵源。

## 更新資料

```bash
# 在含 data/roster.tsv 的工作目錄
python3 tools/nstc.py      # 擷取國科會研究人才資料 → data/nstc/*.json
python3 tools/analyze.py   # 判定、統計 → site/data.js、site/data.json
```

`data/raw/` 保存本次擷取的原始資料（國科會 JSON、師資名單、獎章名單文字檔），方便核對。
